The name is resolved against the running After Effects, so a wrong one fails loudly. The id is only the fallback for a localised AE — and a wrong-but-valid id silently fires some other command, which is why the name goes first. Test-fire before you trust either.

After Effects shares one ExtendScript namespace, so a snippet can call into a script you already have — but only once that script has been loaded. Naming the global and the file makes pieFX load it on demand, which is the difference between a wheel that works on the first flick and one that works on the second.

Relative paths resolve against pieFX's install folder, so a script that ships with the product travels with it. A bare filename is searched in After Effects' own Scripts folders. Most panel scripts pop their palette when run this way — a snippet is usually what you actually want.
